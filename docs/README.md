# Docs

Documentation of the project. Each concept is documented once, in the folder it belongs to, and
linked from everywhere else.

| Folder | Content |
|---|---|
| [`adr/`](./adr) | Architecture decision records: one file per decision, numbered |
| [`architecture/`](./architecture) | How the system is built and why |
| [`guides/`](./guides) | How to do something once: setup, onboarding, bootstrap |
| [`runbooks/`](./runbooks) | Steps to follow for a recurring or urgent operation |

A client project adds `functional/`, `deployment/`, `operations/` and `handover/` (see the
`repo-standard` skill). Add subfolders only when there is content for them, and list them here.
